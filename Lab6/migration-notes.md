

# Лабораторна робота №6 | Міграції та робота з Prisma ORM

## 1. Додавання нової моделі (Review)

**Опис:** Створено нову модель `Review` для зберігання відгуків користувачів на книги. Це дозволяє реалізувати систему рейтингів у бібліотеці.

**Встановлені зв'язки:**
* Зв'язок **One-to-Many**: Одна книга (`book`) може мати багато відгуків (`Review`).

**Фрагмент оновленої схеми:**

```prisma
model Review {
  id      Int     @id @default(autoincrement())
  rating  Int
  comment String?
  book_id String
  book    book    @relation(fields: [book_id], references: [book_id])
}

model book {
  book_id String   @id @db.VarChar(50)
  // ... інші поля
  Review  Review[] // Зворотній зв'язок для моделі Review
}
````

## 2\. Модифікація таблиці Student

Для розширення функціоналу користувачів було додано нове поле для визначення преміум-статусу.

**Оновлена структура моделі:**

```prisma
model student {
  student_card_id Int     @id
  full_name       String  @db.VarChar(255)
  email           String  @unique @db.VarChar(150)
  is_pro          Boolean @default(false) // Нове поле: статус про-аккаунта
  loan            loan[]
}
```

## 3\. Управління міграціями

Зміни були синхронізовані з базою даних PostgreSQL за допомогою Prisma Migrate.

**Виконані команди:**

1.  `npx prisma migrate dev --name init_lab6` — створення та застосування SQL-міграції.
2.  `npx prisma generate` — оновлення клієнта Prisma для підтримки нових типів у коді.

Всі файли міграцій збережені у папці `prisma/migrations`.
